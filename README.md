# ZYZ_SRDP 项目说明

## 项目概述

本仓库包含 Han 在 ZYZ SRDP（海洋/气候数据可视化与分析）中的代码贡献，主要实现一个 Gradio Web 界面，用于生成区域海表温度、盐度、降水和异常值的动态图像（GIF）。

## 目录结构

- `app_05_06_2023/`
  - `APP.py`：主程序，加载数据、生成图像帧并输出 GIF。
  - `read2.ipynb`：数据分析/实验笔记本。
  - `ready.ipynb`：数据分析/实验笔记本。
- `app_22_06_2023/`
  - `testapp.ipynb`：测试或补充分析笔记本。
- `README.md`：本文件。

## 核心功能

`app_05_06_2023/APP.py` 是项目的核心脚本，主要功能：

1. 加载预处理好的数据文件：
   - `sai_切割.npy`：盐度数据
   - `sal_ano_切割.npy`：盐度异常数据
   - `temp_切割.npy`：温度数据
   - `temp_ano_切割.npy`：温度异常数据
   - `p_2020.mat`：2020 年降水数据
2. 定义时间、经纬度、深度等网格：
   - 经度范围：120°E ~ 127°E，步长 0.1
   - 纬度范围：30°N ~ 40°N，步长 0.1
   - 时间范围：2020-06-01 ～ 2020-08-31
   - 深度层数：0 ~ 29
3. 提供 Gradio 界面用于交互选择：
   - 左右经度、上下纬度
   - 深度层数
   - 日期
   - 时间窗口范围（前后天数）
4. 根据用户参数生成：
   - 盐度剖面图
   - 温度剖面图
   - 降水柱状图
   - 温盐异常时间序列
   - 温度/盐度异常剖面图
   - 区域异常地图
5. 将每帧存储到 `figsave/` 目录，并最终输出 `output.gif`。

## 运行说明

### 依赖环境

推荐安装以下 Python 包：

```bash
pip install gradio numpy matplotlib pandas cartopy pillow scipy tqdm
```

> 注意：`cartopy` 在 Windows 上安装可能需要额外依赖（GEOS、PROJ）。如果遇到问题，请先安装相应底层库。

### 执行程序

1. 进入项目目录：

```bash
cd d:\Git\ZYZ_SRDP\app_05_06_2023
```

2. 确保目录中存在数据文件，并且提前创建 `figsave` 文件夹：

```bash
mkdir figsave
```

3. 运行主程序：

```bash
python APP.py
```

4. 浏览器打开：

```text
http://0.0.0.0:8082
```

5. 在 Gradio 界面中输入参数：
   - `左经度`/`右经度`：120~127
   - `下纬度`/`上纬度`：30~40
   - `level`：0~29 深度层数
   - `时间`：格式 `YYYYMMDD`，例如 `20200722`
   - `前后时间`：控制时间窗口大小

6. 输出结果：
   - `output.gif`
   - 中间帧图像保存在 `figsave/` 文件夹中

## 维护建议

- 代码中存在硬编码路径，例如 `'.\figsave'`、`output.gif`，建议后续改为参数化或配置文件。
